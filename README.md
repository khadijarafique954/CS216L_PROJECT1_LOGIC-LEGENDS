**Description:**
This is a simple console-based Student Record System.
It stores student records using a singly linked list.
It uses a stack to undo the last deleted student.
Linear search is used to search students by ID.
Bubble sort is used to sort students by GPA.

**Data Structures Used:**
1. Singly Linked List
2. Stack

Searching Algorithm:
Linear Search

Sorting Algorithm:
Bubble Sort

**Features:**
1. Add Student
2. Display Students
3. Search Student
4. Delete Student
5. Sort Students by GPA
6. Undo Last Delete
7. Show Stack Top
8. Show Stack Size
9. Show Time Complexity

**Time complexity:**

| Operation   | Time Complexity |
| ----------- | --------------- |
| Insert      | O(1)            |
| Delete      | O(n)            |
| Search      | O(n)            |
| Bubble Sort | O(n²)           |
| Push        | O(1)            |
| Pop         | O(1)            |
